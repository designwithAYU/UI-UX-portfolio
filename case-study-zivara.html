03 / CASE STUDY

Zivara

Mental Wellness Mobile Experience

A mobile wellness experience designed around simple daily check-ins, guided activities and progress tracking. The focus was on creating a calm interface without making the experience feel overwhelming.

ROLE UI/UX Designer
TYPE Mobile App
TOOLS Figma
FOCUS UX · UI · Prototype
01
PROJECT OVERVIEW

Making wellness feel simple.

Zivara explores how a wellness application can make everyday self-care easier to approach. Instead of presenting users with too many features at once, the experience focuses on a small number of meaningful actions such as checking in, completing a short activity and reviewing personal progress.

01 Simple navigation

Keep important actions easy to find without overwhelming the user.

02 Calm visual language

Use soft colors, spacing and hierarchy to create a comfortable interface.

03 Small daily actions

Break the experience into manageable activities rather than long workflows.

02
DESIGN CHALLENGE

How can the experience feel supportive without becoming complicated?

Wellness applications often contain several different activities, tracking features and personal settings. The design challenge was to organize these elements into a straightforward experience that users could understand quickly.

I focused on reducing visual noise, establishing a clear navigation structure and giving the most important daily actions greater visual priority.

UI EXPLORATION

Turning the structure into a calm visual system.

The visual direction uses soft neutrals, muted greens and generous spacing to create a calmer interface while maintaining clear hierarchy and readable information.

06
DESIGN DECISIONS

Small decisions that shape the experience.

01

Clear hierarchy

Important daily actions are visually stronger than secondary information so users can understand what to do next.

02

Consistent navigation

A persistent bottom navigation keeps the main areas accessible without forcing users through long menus.

03

Soft visual language

Muted colors and generous spacing help the interface feel approachable without sacrificing contrast.

04

Focused screens

Each screen has one primary purpose instead of trying to display every available feature at once.
